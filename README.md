The funniest one-line commit message an AI agent would leave after a long night fixing its own bugs. One line, 134 characters: every fix bred the next bug, the original bug survived the night, and the agent clocks out at 04:00.

> fix: removed the bug I added while fixing the bug I added while fixing the bug. The original bug is still there. Logging off at 04:00.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program writes the commit message to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), then reads it back to prove the gate holds: one line, 1–200 characters. Node 22, standard library only, no network, fully deterministic.
